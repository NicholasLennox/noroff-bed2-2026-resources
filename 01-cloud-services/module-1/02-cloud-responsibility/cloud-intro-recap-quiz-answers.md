# Cloud Computing Recap Quiz — Answer Key

**1. Answer: A) Rapid Elasticity**
Capacity growing and shrinking automatically to match demand.

**2. Answer: A) Resource Pooling**
Hardware shared between multiple, unrelated consumers (multi-tenant), with location independence — customers don't know or care which physical machine they're on.

**3. Answer: A) On-Demand Self-Service**
Defined by the *absence* of human interaction from the provider's side — no salesperson, no support call, just self-service provisioning.

**4. Answer: A) Measured Service**
Usage is automatically tracked with metrics appropriate to the service (hours, GB, etc.), giving both provider and consumer visibility into exactly what was used — this is what makes utility-style billing possible.

**5. Answer: A) Broad Network Access**
Available over the network from heterogeneous platforms (phone, laptop, desktop) via standard mechanisms — the device and location don't matter, only the internet connection does.

**6. Answer: A) Cloud Auditor**
Defining feature is *independence* — someone with no financial stake in the vendor, conducting an unbiased assessment (often of privacy/security compliance).

**7. Answer: A) Cloud Carrier**
Provides connectivity and transport between provider and consumer, without selling any cloud services itself — typically an ISP or telecom.

**8. Answer: A) Cloud Broker**
Doesn't own infrastructure and doesn't perform independent checks — instead manages and negotiates the relationship between consumer and provider on the client's behalf.
