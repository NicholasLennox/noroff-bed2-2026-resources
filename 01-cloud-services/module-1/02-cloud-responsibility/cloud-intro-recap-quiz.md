# Cloud Computing Recap Quiz

For each scenario, work out which concept from yesterday's class is actually being described. These aren't the same examples used in class — think through the concept rather than trying to remember a phrase.

**1.** An online store automatically adds extra server capacity during a Black Friday sale, then scales back down the following week once traffic normalizes — all without anyone manually configuring anything.

- A) Rapid Elasticity
- B) Resource Pooling
- C) On-Demand Self-Service
- D) Measured Service

**2.** Two competing companies run their applications on the same cloud provider's physical servers at the same time. Each company's data is completely walled off from the other's, and neither company knows — or needs to know — exactly which machine their workload is running on.

- A) Resource Pooling
- B) Rapid Elasticity
- C) Broad Network Access
- D) On-Demand Self-Service

**3.** A student signs up for a cloud storage account through a website, is using it within two minutes, and at no point speaks to or emails anyone at the company.

- A) On-Demand Self-Service
- B) Broad Network Access
- C) Measured Service
- D) Rapid Elasticity

**4.** A company's monthly cloud invoice itemizes charges based on exactly how many hours their virtual machines ran and how many gigabytes of storage they used — similar to how a utility company bills for electricity or water.

- A) Measured Service
- B) On-Demand Self-Service
- C) Resource Pooling
- D) Rapid Elasticity

**5.** A researcher accesses the same cloud-hosted dataset equally well from their office desktop, their phone on the train, and a friend's laptop abroad — the device and location don't matter, only having an internet connection does.

- A) Broad Network Access
- B) Resource Pooling
- C) Rapid Elasticity
- D) On-Demand Self-Service

**6.** A university wants someone with no financial relationship to a cloud vendor to independently check whether the vendor is properly encrypting student records and complying with privacy law.

- A) Cloud Auditor
- B) Cloud Broker
- C) Cloud Carrier
- D) Cloud Consumer

**7.** A telecom company doesn't sell any cloud storage, software, or services of its own — but its fibre network is what physically carries data between a business and its cloud provider.

- A) Cloud Carrier
- B) Cloud Provider
- C) Cloud Broker
- D) Cloud Auditor

**8.** A small IT consultancy doesn't own any servers. Instead, it helps a client compare cloud vendors, negotiates the contract terms on the client's behalf, and manages the ongoing relationship once the client signs up.

- A) Cloud Broker
- B) Cloud Provider
- C) Cloud Carrier
- D) Cloud Auditor
