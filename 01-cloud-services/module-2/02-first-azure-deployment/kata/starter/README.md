# Product API - kata 2 starter

The starting point for **BED2-CDS-Kata-2**. Copy this folder somewhere of your
own before you change anything.

The three endpoints work and the tests pass, provided a MySQL database happens to
be sitting on the exact host, port and credentials written into
`src/config/database.js`. Making that stop being true is the exercise.

Nothing in here is an example of how to configure an application. Read the kata.
