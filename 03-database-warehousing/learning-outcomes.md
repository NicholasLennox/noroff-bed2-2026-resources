# Course Learning Outcomes

## 1. Knowledge

The candidate:

- Has knowledge of the concept and purpose of using data warehousing to analyse and report data.
- Has knowledge of theories and main approaches used to build a data warehouse system.
- Has knowledge of industry-relevant reporting tools used in data warehouse systems.
- Has insight into their own opportunities for development in the field of data warehousing.

## 2. Skills

The candidate:

- Can find and refer to information relating to data warehousing.
- Can explain vocational choices when choosing an approach to build a data warehouse system.
- Can explain vocational choices when using tools to build reports.
- Can reflect on their own data reporting and data warehouse practices.

## 3. General Competence

The candidate:

- Can plan and carry out tasks aimed at building a data warehouse system, independently or as part of a group, in accordance with ethical requirements and principles of data usage.
- Can plan and carry out tasks to generate reports using data extracted from a data warehouse.
- Can contribute to data warehouse system development and data reporting.
